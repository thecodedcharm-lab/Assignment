# C. Operator Precedence Practice

### 9. What is the result?

```python
10 + 5 * 2
```

Show the order of calculation.

**Answer:**

Multiplication is performed before addition.

```text
10 + 5 * 2
10 + 10
20
```

**Result:**

```text
20
```

---

### 10. What is the result?

```python
(10 + 5) * 2
```

Explain why it is different from Question 9.

**Answer:**

The expression inside parentheses is calculated first.

```text
(10 + 5) * 2
15 * 2
30
```

**Result:**

```text
30
```

It is different because parentheses have higher precedence than multiplication.

# D. Floor Division and Modulus

### 17. A class has 23 students. If each group contains 5 students:

* How many complete groups can be made?
* How many students will remain?

Use `//` and `%`.

**Answer:**

```python
students = 23
students_per_group = 5

complete_groups = students // students_per_group
remaining_students = students % students_per_group

print("Complete groups:", complete_groups)
print("Remaining students:", remaining_students)
```

**Output:**

```text
Complete groups: 4
Remaining students: 3
```

Therefore, **4 complete groups** can be made and **3 students** will remain.

### 18. A shop has 47 products. Each box can contain 6 products.

Write a Python program to find:

* Number of complete boxes
* Number of remaining products

Therefore, **7 complete boxes** can be filled and **5 products** will remain.

### 20. Write a small Python program that calculates the total cost of 4 products when each product costs ₹75. Then calculate how many complete groups of ₹100 can be made from the total using floor division, and what amount remains using modulus.

**Answer:**

```python
number_of_products = 4
price_per_product = 75

total_cost = number_of_products * price_per_product

complete_groups = total_cost // 100
remaining_amount = total_cost % 100

print("Total cost:", total_cost)
print("Complete groups of ₹100:", complete_groups)
print("Remaining amount:", remaining_amount)
```

**Output:**

```text
Total cost: 300
Complete groups of ₹100: 3
Remaining amount: 0
```

Therefore, the total cost is **₹300**, which contains **3 complete groups of ₹100**, with **₹0 remaining**.
