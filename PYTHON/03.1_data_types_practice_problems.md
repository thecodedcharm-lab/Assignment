# Practice Problems: Data Types in Python

## C. `type()` Practice

### 18. What will `type()` identify for the following?

```python
x = 25
print(type(x))
```

**Answer:**

`25` is an integer, so `type()` identifies it as `int`.

**Output:**

```text
<class 'int'>
```

### 25. Create three variables:

```text
a → 50
b → 50.0
c → "50"
```

Use `type()` to identify the type of each variable.

**Answer:**

```python
a = 50
b = 50.0
c = "50"

print(type(a))
print(type(b))
print(type(c))
```

**Output:**

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

**Explanation:**

* `50` is an integer (`int`).
* `50.0` is a floating-point number (`float`).
* `"50"` is a string (`str`).

### 26. Create two variables:

```text
a → True
b → "True"
```

Use `type()` and explain why their types are different.

**Answer:**

```python
a = True
b = "True"

print(type(a))
print(type(b))
```

**Output:**

```text
<class 'bool'>
<class 'str'>
```

**Explanation:**

`True` without quotation marks is a Boolean value, so its type is `bool`.

`"True"` is enclosed in quotation marks, so it is treated as a string, and its type is `str`.

### 28. Create a variable called `value`.

1. First assign an integer to it.
2. Use `type()` to identify its type.
3. Reassign a string to it.
4. Use `type()` again.
5. Explain what changed.

**Answer:**

```python
value = 100
print(type(value))

value = "Python"
print(type(value))
```

**Output:**

```text
<class 'int'>
<class 'str'>
```

**Explanation:**

Initially, `value` contains `100`, which is an integer, so its type is `int`.

After reassignment, `value` contains `"Python"`, which is a string, so its type becomes `str`.

The value and its data type changed because the variable was reassigned.

### 30. Create a small program that demonstrates the difference between:

```text
10
10.0
"10"
True
"True"
None
"None"
```

Use `type()` for every value and write the identified type beside each one in your explanation.

**Answer:**

```python
value1 = 10
value2 = 10.0
value3 = "10"
value4 = True
value5 = "True"
value6 = None
value7 = "None"

print(type(value1))
print(type(value2))
print(type(value3))
print(type(value4))
print(type(value5))
print(type(value6))
print(type(value7))
```

**Output:**

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'str'>
<class 'NoneType'>
<class 'str'>
```

**Explanation:**

| Value    | Data Type  |
| -------- | ---------- |
| `10`     | `int`      |
| `10.0`   | `float`    |
| `"10"`   | `str`      |
| `True`   | `bool`     |
| `"True"` | `str`      |
| `None`   | `NoneType` |
| `"None"` | `str`      |

Quotation marks are important because values inside quotation marks are treated as **strings**.
