# Practice Problems: Variables in Python

## C. Code Understanding

### 18. What values will the following variables refer to?

```python
name = "Rahul"
age = 18
city = "Patna"
```

**Answer:**

```text
name → "Rahul"
age → 18
city → "Patna"
```

---

### 19. What is the final value of `age`?

```python
age = 18
age = 19
```

**Answer:**

The final value of `age` is **19**.

The variable `age` is first assigned the value `18`. Then it is reassigned the value `19`, so the current value becomes `19`.

---

### 20. What is the final value of `name`?

```python
name = "Rahul"
name = "Amit"
name = "Riya"
```

**Answer:**

The final value of `name` is **"Riya"**.

The variable is reassigned each time, so the most recently assigned value is the current value.

---

### 21. Explain what happens in this program.

```python
student_name = "Rahul"
student_age = 18

student_age = 19
```

**Answer:**

The variable `student_name` is assigned the value `"Rahul"`.

The variable `student_age` is first assigned the value `18`. Then, it is reassigned the value `19`.

Therefore, the final values are:

```text
student_name → "Rahul"
student_age → 19
```

---

### 22. What values will `a`, `b`, and `c` refer to?

```python
a, b, c = 10, 20, 30
```

**Answer:**

The values are assigned in the same order:

```text
a → 10
b → 20
c → 30
```

This is called **multiple assignment**.

---

### 23. What values will `x`, `y`, and `z` refer to?

```python
x = y = z = 100
```

**Answer:**

All three variables will have the value `100`.

```text
x → 100
y → 100
z → 100
```

This assigns the same value to multiple variables in one statement.

### 26. Write a program that assigns a value to a variable called `marks`, then reassigns a new value to `marks`.

Explain the value before and after reassignment.

**Answer:**

```python

print(marks)

marks = 90
print(marks)
```

**Explanation:**

Before reassignment, the value of `marks` is `75`.

After reassignment, the value of `marks` becomes `90`.

Therefore:

```text
Before reassignment → 75
After reassignment → 90
```

### 30. Create a small Python program that stores a student's name and age, reassigns the age to a new value, and then displays the current values.

Use:

* A useful comment
* Meaningful variable names
* `snake_case`
* Reassignment

**Answer:**

```python
# Store student information and update the student's age

student_name = "Khushi"
student_age = 18

# Reassign the age to a new value
student_age = 19

print("Student Name:", student_name)
print("Student Age:", student_age)
```

**Explanation:**

The program stores the student's name in `student_name` and the initial age in `student_age`.

The age is then reassigned from `18` to `19`.

The final output is:

```text
Student Name: Khushi
Student Age: 19
```
