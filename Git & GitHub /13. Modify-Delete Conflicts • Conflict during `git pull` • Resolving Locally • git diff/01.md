Assignment 1
Conflict during git pull

Goal: Face and resolve a conflict that appears when you run git pull origin main.

On GitHub (remote main), create a file welcome.txt with the content:
Welcome to Git class
Commit it directly on GitHub.
On your local main, create the same file welcome.txt with different content:
Welcome to Day 13
Run:
git add welcome.txt
git commit -m "Add welcome.txt locally"
git pull origin main
A conflict will appear. Resolve it by keeping both lines (or any final version you prefer).
Remove all conflict markers, then:
git add welcome.txt
git commit -m "Resolve pull conflict in welcome.txt"
git push origin main
