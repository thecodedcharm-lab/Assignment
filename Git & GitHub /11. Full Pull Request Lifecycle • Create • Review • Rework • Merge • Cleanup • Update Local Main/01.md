Assignment 1 – Complete PR Lifecycle with feature/contact-form (Mandatory)
Goal: Practice the full cycle: branch → file → commit → push → PR → merge → cleanup.

Update main:
git checkout main && git pull origin main
Create branch:
git checkout -b feature/contact-form
Create file contact.html with a simple heading and a short paragraph about a contact form.
Stage, commit and push:
git add contact.html
git commit -m "Add contact form page"
git push -u origin feature/contact-form
On GitHub: Open a Pull Request (base = main, compare = feature/contact-form). Write a clear title and description.
Merge the Pull Request using “Create a merge commit”.
Delete the remote branch (GitHub “Delete branch” button or git push origin --delete feature/contact-form).
Update local main using the two-command method:
git checkout main
git fetch origin main
git merge origin/main
Delete local branch:
git branch -d feature/contact-form
Take screenshots of:
(a) the merged PR
(b) terminal after fetch + merge
(c) git branch showing the branch is gone
Submit: Merged PR link + the 3 screenshots listed above.
